# Architecture

SSH gateway forces the bbs transport user into bbs-login. authd authenticates BBS accounts using Argon2id through libsodium. sessiond validates session tokens against Unix peer credentials. A privileged gateway supervisor hands authenticated users into distinct Unix identities. Mail, board, file, chat, game, door, information and IRC bridge services use bounded SOCK_SEQPACKET JSON RPC through separately mounted socket volumes.

The local mail authority retains no network interface. A separate `mail-exchange` process shares only the mail volume, account-lookup socket, peer-key directory and its TLS files. It accepts pinned-TLS, HMAC-authenticated text mail from explicitly paired BBS installations and drains the durable outbound queue. BBS display name, stable network ID, peer routes and delivery state live in the mail database; peer shared secrets are mode-0600 files in the private mail volume.

Service UIDs: auth 21001, session 21002, mail 21003, board 21004, file 21005, chat 21006, IRC bridge 21007, external IRC 21008, information 21009, game 21010, door 21011, music 21012. Gateway transport UID 29999; IRC UID 10002. Backend processes are non-root. Gateway SSH/supervisor startup requires narrowly scoped capabilities and root.

SQLite stores remain private service volumes. Information, IRC bridge and mail exchange require network connectivity. Other core backends have `network_mode: none`. Internal ngIRCd uses a private Docker network with no published ports. The exchange port is bound to loopback by default and is the only base application protocol designed for optional peer exposure.

The optional MarsAmp service is split across two interfaces. Its Unix RPC socket accepts catalog, curated-playlist, and playback commands from authenticated BBS sessions. Its HTTP listener is bound to the host loopback interface for an operator-provided HTTPS reverse proxy. It mounts the primary NAS01 and secondary UNR01 libraries read-only and stores only its derived catalog and playlist matches in a private volume. Redeeming a pairing ticket exchanges the originating SSH session for a revocable music-only session with a maximum eight-hour lifetime. The session authority shows this lease separately from SSH sessions and lets a Sysop terminate it. The Mac intake share is outside this architecture.
